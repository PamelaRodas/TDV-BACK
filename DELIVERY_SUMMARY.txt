🚀 CÓMO INICIAR
═══════════════════════════════════════════════════════════════════════════════

1️⃣ INSTALAR DEPENDENCIAS

   # Node.js
   npm install

   # Python
   cd python-analytics
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt

2️⃣ INICIAR SERVICIOS (Terminales separadas)

   Terminal 1 - API Python:
   cd python-analytics
   venv\Scripts\activate
   python -m uvicorn api:app --reload --port 8000

   Terminal 2 - Backend Node.js:
   npm run dev

3️⃣ VERIFICAR SALUD

   curl http://localhost:5000/api/health
   curl http://localhost:8000/health

4️⃣ PRUEBA RÁPIDA

   curl http://localhost:5000/api/analytics/analizar \
     -H "Content-Type: application/json" \
     -d '{"registros":[{"cat":"A","val":10},{"cat":"B","val":20}]}'
